# @vietz-design/react

React implementation of the vietz-design design system.

## Install

```bash
pnpm add @vietz-design/react @ark-ui/react
```

## Usage

```tsx
import '@vietz-design/react/styles.css'
import { Accordion, Button, Tag, SurfaceCard } from '@vietz-design/react'
```

## Included today

- Accordion
- Button
- Tag
- SurfaceCard
- InlineCode
- design tokens and base styles

See the workspace Storybook app for visual documentation.
